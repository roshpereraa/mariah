# Drop your own copy of the song here

The 1994 recording of *All I Want for Christmas Is You* is copyrighted, so it is
not redistributed in this repository.

If you have a licensed copy, save it here as:

```
audio/all-i-want-for-christmas-is-you.mp3
```

The player checks for that file first and will use it automatically — nothing
else to configure. Files in this folder are gitignored, so your copy stays local
unless you deliberately commit it.

If no file is present the player falls back to the official upload via YouTube's
embed player, and then to an original sleigh-bell mix generated live in the
browser. See `js/config.js`.
